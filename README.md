# Anamorphic De-Squeeze (Android)

## Get the APK — no coding tools needed
1. Create a free account at github.com.
2. Click **+ → New repository**, name it `AnamorphicDesqueeze`, choose **Private**, create it.
3. On the empty repo page click **uploading an existing file**, drag in *everything inside* this
   folder (including the hidden `.github` folder — on Mac press Cmd+Shift+. to show it), then **Commit**.
4. Open the **Actions** tab. A "Build APK" run starts automatically (~5–8 min).
   If it doesn't, choose "Build APK" → **Run workflow**.
5. When it shows a green tick, open the run, scroll to **Artifacts**, download `AnamorphicDesqueeze-apk`,
   unzip it, and copy the `.apk` to your phone.
6. On the phone, open the APK and allow "Install unknown apps" when asked.

If the run shows a red ✗, open it, copy the error text, and paste it back to Claude to fix.

## Build locally (optional)
Install Android Studio → File → Open this folder → Build → Build APK(s).
